О DocShift

Учебное приложение для миграции устаревшей системы документооборота.

MVP 1.0

Зачем нужен DocShift?

Приложение переносит данные из старых таблиц SQLite в новую структуру, сохраняя исходные идентификаторы legacy_id. Оно показывает соответствие полей, преобразует даты и статусы, проверяет обязательные значения и связи, фиксирует ошибки и сохраняет историю операций.

Принцип работы

legacy.db→Проверка + mapping→cloud.db

Особенности учебной версии

Программа работает локально на 127.0.0.1:5000, использует Python, встроенный HTTP-сервер, sqlite3, Jinja2, HTML и CSS. Не требует Flask, pip, интернета или прав администратора. Нужен только Python 3.10 или новее.

Значения file_path сохраняются как текстовые ссылки на файлы. При загрузке только SQLite переносятся записи базы. В режиме переноса папки копируются также физические файлы с сохранением вложенных каталогов.

Новая структура

  • departmentsid, legacy_id, name, migrated_at
  • usersid, legacy_id, full_name, email, migrated_at
  • documentsid, legacy_id, title, author_id, department_id, created_at, status, file_path, migrated_at

FOREIGN KEY обеспечивает связи между документами, пользователями и отделами.
